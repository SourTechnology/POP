# POP!

A single-file link-in-bio site where users can sign up or log in, create a POP Domain, add a bio and links, and preview their page.
Run it

Save the website code as index.html.
Open index.html in a browser.
Create an account, then customize and save your POP Domain.

# Features

Sign-up and login screens
POP Domain name and bio editor
Add and remove links
Live page preview
Saves demo accounts and domains in browser localStorage
Responsive layout

# Important
This is a front-end demo. Account data, including passwords, is stored in localStorage and is not secure. Don’t use real passwords. For a public site, add a backend with secure authentication and hosting. A .pop name shown here is a preview label, not a registered domain.
